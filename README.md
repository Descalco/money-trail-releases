# Money Trail — Downloads

Money Trail é uma app de finanças pessoais para Windows. **Todos os dados ficam no teu computador**: não há conta, não há servidor, nada é enviado para lado nenhum.

## Instalar

1. Vai a **[Releases](https://github.com/Descalco/money-trail-releases/releases/latest)** e descarrega o ficheiro `Money.Trail_X.Y.Z_x64-setup.exe`.
2. Abre-o. O Windows vai mostrar uma caixa azul **"O Windows protegeu o seu PC"**. É normal: a app não tem um certificado pago da Microsoft.
   - Clica em **Mais informações** e depois em **Executar mesmo assim**.
3. Segue o instalador. A Money Trail fica no menu Iniciar.

## Atualizações

Quando houver uma versão nova, a app avisa-te no **número da versão, na barra lateral**. Clica, descarrega o novo instalador e corre-o por cima do antigo. **Os teus dados não são tocados por uma atualização.**

## Os teus dados

Ficam num único ficheiro encriptado: `%APPDATA%\com.moneytrail.app\money_trail.db`.
A app faz um backup automático por dia. Também podes fazer um em **Definições → Dados → Segurança dos dados → Fazer backup agora**.

## Encontraste um problema?

Carrega na **boia salva-vidas** no canto inferior direito, descreve o que aconteceu e guarda. Fica um ficheiro no Ambiente de Trabalho: envia-o ao Pedro. Valores e nomes vão escondidos por defeito.

---

`latest.json` neste repo é o que a app consulta para saber se há versão nova. Não o apagues.
